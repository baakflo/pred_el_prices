Why L1 deletes weights and L2 only shrinks them

The two objectives (identical data-fit term, different penalty):

$$\hat{w}_{\text{ridge}} \;=\; \arg\min_{w}\; \underbrace{\lVert y - Xw \rVert_2^2}_{\text{data fit}} \;+\; \alpha \underbrace{\sum_j w_j^2}_{\lVert w\rVert_2^2}$$

$$\hat{w}_{\text{lasso}} \;=\; \arg\min_{w}\; \underbrace{\lVert y - Xw \rVert_2^2}_{\text{data fit}} \;+\; \alpha \underbrace{\sum_j |w_j|}_{\lVert w\rVert_1}$$

Closed-form solutions in the 1D / uncorrelated case (what the bottom plot draws), with \(w^{\text{OLS}}\) the unregularized weight:

$$\hat{w}_{\text{ridge}} = \frac{w^{\text{OLS}}}{1+\alpha} \qquad\qquad \hat{w}_{\text{lasso}} = \operatorname{sign}\!\left(w^{\text{OLS}}\right)\, \max\!\left(|w^{\text{OLS}}| - \tfrac{\alpha}{2},\; 0\right)$$

The \(\max(\cdot,0)\) is the dead zone: a weight smaller than the rent \(\alpha/2\) is set to exactly zero. The squared penalty has derivative \(2\alpha w \to 0\) near the origin — the push toward zero fades out, so ridge never completes the kill; the absolute value keeps a constant push \(\pm\alpha\) all the way in.

The black dot is the unregularized least-squares solution — drag it around. The blue ellipses are contours of the data-fit loss (their tilt = feature correlation). The shaded region is the penalty ball that the regularized solution (red dot) effectively lives on: a diamond for L1, a circle for L2. The orange curve is the regularization path — where the solution travels as α goes from 0 to ∞.

The same thing in 1D: every feature pays rent

Input: the weight the data wants. Output: the weight after regularization, at the current α. The LASSO has a dead zone — weights that can't pay the rent α are set to exactly zero. Ridge divides by a constant: small weights get smaller, but never zero.

What to try

  • Drag the black dot close to an axis (data barely needs one feature): the L1 red dot snaps exactly onto the axis — that weight is deleted. The L2 dot never quite gets there.
  • Crank α up: watch the L1 path hit an axis and then travel along it (one weight stays dead while the other shrinks). The L2 path is a smooth curve into the origin that never touches an axis first.
  • Set ρ ≈ 0.9 (strongly correlated features, like our neighboring price lags): the ellipses become a narrow tilted valley. Nudge the black dot slightly and watch the L1 solution jump between the two axes — that is the coefficient instability of LASSO under correlation. Predictions (the loss value) barely change; the attribution flips.

Connection to LEAR: it solves exactly the left panel, but in 247 dimensions — one diamond corner for every subset of features. The AIC picks α each morning, i.e. decides how expensive the rent is today; typically only a few dozen of the 247 features can afford to stay. The result is a different, interpretable feature set for every delivery hour.
