The noon slice, with real numbers

Freeze everything except the day-d noon exog values and look at what each model is allowed to learn. Red weights are free; grey structure is frozen before training.

extended (4 free weights on this slice):
pricê = … + βload·62.4 + βwon·8.5 + βwoff·3.1 + βsol·33.3
academic (2 free weights — RES weights tied to each other):
pricê = … + βload·62.4 + βres·(8.5+3.1+33.3)   ← forces βwon=βwoff=βsol
residual-only (1 free weight — load weight tied to −RES weight):
pricê = … + β·(62.4 − 8.5 − 3.1 − 33.3)   ← additionally forces βload = −βres

So the three cases are nested: anything residual-only can express, academic can imitate (set βload=β, βres=−β), and anything academic can express, extended can imitate. Going down the ladder never adds information — it freezes weights, trading expressiveness for fewer parameters to estimate. In ANN terms: a frozen linear layer [+1,−1,−1,−1] inserted before the model.

But note the Sunday row: the −37.1 needs RES specifically (subsidized bids below zero) plus weekend demand — a residual-only model sees −1.3 GW and cannot tell a windy winter night from a sunny summer Sunday. The academic pair can, because it keeps load and RES as separate axes.
