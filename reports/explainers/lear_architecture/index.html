3 — What window size did to measured accuracy

On the calm benchmark years, long windows win: more samples, stable regime, variance reduction pure profit (56 d → 4.59 MAE, 1092 d → 3.91). On our 2019-2026 data one window (364 d) is measured so far, and its failure mode is visible in time, not in the average: rMAE 0.588 in 2021 — the window kept paying attention to a market that no longer existed during the crisis run-up. Window length is a bias–variance dial where "bias" means regime staleness. The plan's answer: stop asking one window to solve non-stationarity; feed the regime (fuel, carbon) to the model as features.
